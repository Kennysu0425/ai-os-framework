# Open Source Scope v1

## Origin and Attribution

`ai-os-framework` was created by [Kenny Su](https://www.kdan.com/leadership), Founder, Chairman & CEO of [KDAN](https://www.kdan.com/).

It is extracted from a private AI OS design effort and published as a reusable framework for governable multi-agent systems.

This repository is an independent open-source framework. It should not be interpreted as an official KDAN product unless explicitly stated.

## Keep private

- personal memory records
- private CRM/email data
- company-specific digital twin runtime
- private tokens and secret env files
- live personal workflows
- private trading logic or live market execution rules
- internal company documents
- raw email, calendar, or relationship data

## Public Boundary

The public repo may include:

- generic control-plane design
- subsystem contract templates
- War Room examples
- demo data
- portability patterns
- security and privacy guidance

The public repo must not include:

- private source data
- customer data
- personal identity graphs
- private memory exports
- production secrets
- machine-local `.env` files
