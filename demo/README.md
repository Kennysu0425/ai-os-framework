# Demo

Start here after reading the repository root `README.md`.

## Demo entry points

- `index.html`
  - lightweight landing page for the demo experience
- `war_room/index.html`
  - minimal operator-facing War Room view

## Recommended flow

1. Run:

   ```bash
   bash scripts/bootstrap.sh
   ```

2. Open:

   - `demo/index.html`

3. From there, open:

   - `demo/war_room/index.html`

The demo consumes:

- `output/war_room_snapshot.json`

which is generated by:

- `scripts/build_demo_war_room_snapshot.py`
